# 망막 혈관 굴곡도와 당뇨망막병증(DR) 등급: FIVES 학습부터 APTOS 분석까지

U-Net으로 안저 영상의 망막 혈관을 분할하고, 혈관 중심선에서 세그먼트별 **굴곡도(tortuosity)** 를 정량화한 뒤, **굴곡도가 DR 등급과 어떤 관계가 있는지** 분석한 Kaggle 노트북입니다. 한 노트북에서 전 과정을 실행합니다.

- 노트북: `fundus-tortuosity-dr-full-kaggle.ipynb`
- 실행 환경: Kaggle Notebook, GPU T4 ×2
- 데이터: FIVES(분할 학습·평가, 800장), APTOS 2019(DR 등급 분석, 3,662장)

---

## 1. 핵심 결과

| 질문 | 답 |
|---|---|
| 혈관 분할은 잘 되는가 | FIVES test **Dice 0.908**, clDice 0.918, AUC 0.994 |
| 어떤 굴곡도 지표를 믿을 수 있는가 | **SOAM** (정답–예측 일치도 ICC 0.83). DM(0.33)·ICM(0.43)은 신뢰도 낮음 |
| 모델이 DR 영상에서 굴곡도를 부풀리는가 | 아니요. 예측은 모든 군에서 약간 낮게 재며, DR군의 오차가 가장 작은 편 |
| DR 등급이 높을수록 굴곡도가 높은가 (APTOS) | **예, 약하지만 일관된 양의 연관.** SOAM Spearman ρ = **0.29** [0.25, 0.32] |
| 혈관 밀도·화질·파편화를 보정해도 남는가 | 예. SOAM 부분 ρ = 0.25, 보정 오즈비 **1.83 / SD** [1.70, 1.97] |
| 분석 조건을 바꿔도 유지되는가 | 예. 민감도 분석 7가지 모두 같은 방향 (SOAM ρ 0.21–0.29) |
| 굴곡도만으로 DR을 판별할 수 있는가 | 제한적. 2등급 이상 판별 AUC 0.65 (SOAM) |

**한 줄 요약:** DR 등급이 높을수록 망막 혈관 굴곡도(SOAM)가 조금씩 높아지는 경향이 있었고, 이 경향은 혈관 밀도·영상 선명도·짧은 조각 비율을 보정하고 분석 조건을 바꿔도 유지되었습니다. 다만 연관의 크기는 약~중간 정도이며, 교란변수(나이, 고혈압 등)를 보정하지 못한 연관성 결과입니다.

## 2. 연구 질문

1. FIVES로 학습한 U-Net은 굴곡도 계산에 필요할 만큼 혈관을 연결성 있게 분할하는가?
2. 예측 마스크로 잰 굴곡도는 정답 마스크로 잰 굴곡도와 얼마나 일치하는가? 분할 오차가 특정 질환군에서 굴곡도를 부풀리는가?
3. APTOS 2019에서 DR 등급과 굴곡도는 어떤 관계인가? 그 관계는 분할 결과의 양, 영상 품질, 병변 인공물로 설명되는가?

## 3. 파이프라인

```
FIVES ─► 전처리(FOV 1024px 정규화, CLAHE) ─► U-Net 학습 ─► 분할 평가
      ─► 스켈레톤 ─► 세그먼트 분리 ─► 굴곡도 5종 ─► 정답/예측 일치도(ICC), 질환군 비교 ─► 결과 저장
APTOS ─► 같은 전처리 ─► U-Net 추론 ─► 굴곡도 ─► 품질 필터 ─► DR 등급 상관 분석 ─► 민감도 분석 ─► 요약
```

| 절 | 내용 |
|---|---|
| 1 | FIVES 자동 탐색(없으면 kagglehub 다운로드), FOV 기준 크기 정규화, CLAHE, 품질 지표 |
| 2 | U-Net(ResNet34) 학습. 학습된 가중치가 Input에 있으면 자동으로 건너뜀 |
| 3 | FIVES 테스트셋 분할 평가 |
| 4 | 스켈레톤 → 세그먼트 → 굴곡도 지표 5종, 합성 곡선 검증 |
| 5 | 정답/예측 굴곡도 일치도, 정답 기준 질환군 비교, 결과 저장(`fives_results.zip`) |
| 6 | APTOS 추론 → 굴곡도 (200장마다 저장, 끊기면 이어서 처리) |
| 7 | 품질 필터, 등급별 기술 통계 |
| 8 | 상관관계 분석 |
| 9 | 민감도 분석, 등급별 굴곡도 지도 |
| 10 | 지표별 자동 판정 요약 |

## 4. 데이터

| 데이터 | 구성 | 용도 |
|---|---|---|
| **FIVES** | 800장, 2048×2048, 전문가 혈관 정답 포함. 정상·AMD·DR·녹내장 각 200장. 공식 분할 train 600 / test 200 | 분할 학습·평가, 굴곡도 신뢰도 평가 |
| **APTOS 2019** | train 3,662장, DR 등급 0–4 (0: 1,805 / 1: 370 / 2: 999 / 3: 193 / 4: 295). 혈관 정답 없음 | DR 등급–굴곡도 관계 분석 |

- FIVES는 Kaggle 사본 `nikitamanaenkov/fundus-image-dataset-for-vessel-segmentation`을 kagglehub로 받았습니다. train 600장 중 질환별 층화로 60장을 검증셋으로 분리했습니다 (train 540 / val 60 / test 200).
- APTOS는 Kaggle 대회 `APTOS 2019 Blindness Detection`의 라벨이 공개된 train 세트를 사용했습니다.

## 5. 방법

### 5.1 전처리
- FOV(촬영 원형 영역) 검출 → 경계 상자로 크롭 → 정사각형 패딩 → **FOV 지름을 1024px로 정규화**. 해상도와 카메라가 다른 FIVES와 APTOS에서 길이·곡률(px)을 같은 척도로 비교하기 위한 단계입니다.
- LAB 색공간 L 채널에 CLAHE(clipLimit 2.0, 8×8) 적용, FOV 밖은 0
- 영상 품질 지표: 선명도(라플라시안 분산, 코드에서는 `blur` 열이며 **클수록 선명**), 밝기, 대비, FOV 비율·종횡비

### 5.2 분할 모델
| 항목 | 설정 |
|---|---|
| 모델 | `segmentation_models_pytorch` U-Net, ResNet34 인코더(ImageNet 사전학습) |
| 입력 | FOV 안쪽 중심 512×512 무작위 패치(에폭당 1,200개), 추론은 1024 전체 영상 |
| 손실 | BCE + Dice + 0.5 × soft clDice (혈관 중심선 연결성 보존) |
| 증강 | 반전, 90° 회전, 약한 아핀, 밝기·대비·감마·색조, 블러. 혈관을 인위적으로 휘게 하는 탄성 변형은 제외 |
| 최적화 | AdamW(lr 3e-4), OneCycle, AMP, batch 8, 80 에폭 |
| 추론 | 좌우·상하 반전 TTA, 검증셋 Dice 최대 임계값(**0.6**) |

### 5.3 세그먼트 추출
1. FOV 가장자리 10px 제외, 100px 미만 연결 요소 제거, 30px 미만 구멍 채움
2. 스켈레톤화 → 분기점 검출(주변 8픽셀의 0→1 전이 3회 이상)
3. 분기점과 주변 1픽셀을 제거해 세그먼트로 분리, 12px 미만 잔가지 제거(2회)
4. 세그먼트 픽셀을 최장 경로로 정렬 → B-spline 평활 → 2px 간격 재샘플
5. 40px 미만 세그먼트 제외

### 5.4 굴곡도 지표
| 지표 | 정의 |
|---|---|
| DM | 호 길이 / 현 길이 (1 = 직선) |
| ICM | DM × (변곡점 수 + 1) |
| **SOAM** | Σ\|방향각 변화\| / 길이 (rad/px) |
| CE | ∫κ² ds / 길이 (곡률 에너지) |
| TD | (n−1)/n · (1/L) · Σ(하위 호/현 − 1), Grisan 2008 |

- 곡률 기반 지표는 스플라인 경계 효과를 피하려고 양 끝 10px을 빼고 계산합니다.
- 영상 단위 값은 세그먼트 길이 가중 평균(`_lw`)을 주 결과로 씁니다.
- **계산 검증:** 직선 DM = 1.0000, 반지름 100px 원호 곡률 0.0099(이론값 0.01), 3주기 사인파 변곡점 5개로 모두 기대값과 일치했습니다.

### 5.5 통계 분석 (APTOS)
- **품질 필터:** FOV 검출 실패·과도한 잘림, 가장 흐린 10%, 극단적 노출(상하위 2%), 세그먼트 10개 미만 제외
- **보정 변수:** 혈관 밀도, 선명도, 짧은 조각 비율(`short_frac`: 80px 미만 세그먼트 비율. 병변 오분할·혈관 끊김의 대리 지표)
- **분석:** Spearman ρ(부트스트랩 2,000회 95% CI), 부분 Spearman ρ, Jonckheere-Terpstra 순서형 경향, Kruskal-Wallis, 순서형 로지스틱 회귀(1 SD당 오즈비), 0등급 대비 Mann-Whitney + Cliff's δ, 2등급 이상 판별 AUC
- **다중비교:** 5개 지표에 Holm 보정
- **민감도 분석 7가지:** 기본, 품질 필터 없음, 선명한 영상 절반, 긴 세그먼트(≥80px), 굵은 혈관(폭 ≥4px), 길고 굵은 혈관, 4등급 제외
- **자동 판정 기준(4개):** ① ρ의 95% CI가 0을 포함하지 않음 ② JT Holm p < 0.05 ③ 부분 ρ가 같은 방향이고 Holm p < 0.05 ④ 민감도 분석 7개 모두 같은 방향

## 6. 결과

### 6.1 분할 학습
- 80 에폭, 에폭당 약 52초 (약 70분)
- 최고 검증 Dice 0.9309 (80 에폭, 임계값 0.5, TTA 없음) → 임계값 0.6 + TTA에서 **0.9336**

### 6.2 분할 성능 (FIVES test 200장, FOV 내부)

| 질환군 | Dice | clDice | Sensitivity | Specificity | AUC |
|---|---|---|---|---|---|
| 정상 | 0.917 | 0.931 | 0.898 | 0.993 | 0.995 |
| AMD | 0.934 | 0.937 | 0.927 | 0.994 | 0.995 |
| DR | 0.912 | 0.924 | 0.893 | 0.994 | 0.995 |
| 녹내장 | 0.867 | 0.879 | 0.854 | 0.994 | 0.990 |
| **전체** | **0.908** | **0.918** | **0.893** | **0.994** | **0.994** |

- 질환군 간 Dice 차이는 유의합니다 (Kruskal-Wallis H = 18.2, p = 0.0004). 녹내장군이 가장 어렵습니다.
- 특이도가 높고 민감도가 상대적으로 낮습니다. 모델이 없는 혈관을 만들기보다 **가는 혈관을 놓치는 쪽으로** 틀린다는 뜻입니다. 정답의 영상당 세그먼트 수 중앙값은 97개, 예측은 84.5개였습니다.

### 6.3 굴곡도 측정 신뢰도 (FIVES test, 정답 vs 예측)

| 지표 | ICC(2,1) | 신뢰도 | Spearman ρ | 질환군 간 오차 차이 p (Holm) |
|---|---|---|---|---|
| DM_lw | 0.330 | 낮음 | 0.717 | 0.253 |
| ICM_lw | 0.426 | 낮음 | 0.700 | 0.304 |
| **SOAM_lw** | **0.830** | **좋음** | **0.902** | 0.006 |
| CE_lw | 0.653 | 보통 | 0.825 | 0.003 |
| TD_lw | 0.671 | 보통 | 0.818 | 0.012 |

- ICC 기준(Koo & Li 2016): 0.75 이상 좋음, 0.5–0.75 보통, 0.5 미만 낮음
- DM의 신뢰도가 낮은 이유는 영상 간 DM 차이가 원래 매우 작기 때문입니다(1.025–1.035). 작은 분할 오차에도 영상 간 순위가 쉽게 바뀝니다.
- SOAM의 (예측 − 정답) 평균 차이는 정상 −0.0008, AMD −0.0004, **DR −0.0004**, 녹내장 −0.0008입니다. 오차 크기가 군마다 다르긴 하지만(p = 0.006), 모델은 모든 군에서 굴곡도를 약간 **낮게** 재며 **DR군에서 부풀리지 않습니다.** 따라서 APTOS에서 보인 등급–굴곡도의 양의 연관을 DR 병변의 오분할 탓으로 설명하기는 어렵습니다.

### 6.4 FIVES 정답 기준 질환군 비교 (800장)

| 질환군 | DM_lw | SOAM_lw | 혈관 밀도 | 세그먼트 수 |
|---|---|---|---|---|
| 정상 | 1.0297 | 0.0079 | 0.115 | 113 |
| AMD | 1.0251 | 0.0069 | 0.098 | 97 |
| DR | 1.0285 | 0.0075 | 0.095 | 80 |
| 녹내장 | 1.0264 | 0.0069 | 0.092 | 86 |

(중앙값) DR vs 정상, Holm 보정 p: DM 1.0, SOAM 0.021, CE 0.012, TD 1.0, 혈관 밀도 < 0.0001

FIVES에서는 **DR군이 정상군보다 더 구불구불하지 않았습니다.** DM·TD는 차이가 없었고, SOAM·CE는 DR군이 오히려 약간 낮았습니다. 가장 뚜렷한 차이는 굴곡도가 아니라 혈관 밀도였습니다(모든 질환군이 정상군보다 낮음). 이 결과와 APTOS 결과의 차이는 7절에서 다룹니다.

**0등급 대비 효과 크기 (Cliff's δ, SOAM_lw)**

| 비교 | δ | Holm p |
|---|---|---|
| 1 Mild vs 0 | 0.26 (작음) | 1.1e-12 |
| 2 Moderate vs 0 | 0.32 (작음) | 2.1e-36 |
| 3 Severe vs 0 | 0.40 (중간) | 2.0e-16 |

δ 기준: 0.15 미만 무시할 만함, 0.15–0.33 작음, 0.33–0.47 중간. 경증(1등급)부터 차이가 나타나고, 중증(3등급) 이후로는 비슷한 수준을 유지합니다.

**2등급 이상(의뢰 필요 DR) 판별 AUC**

| 변수 | AUC [95% CI] |
|---|---|
| SOAM_lw | 0.652 [0.632, 0.670] |
| CE_lw | 0.646 [0.625, 0.666] |
| TD_lw | 0.624 [0.604, 0.645] |
| ICM_lw | 0.613 [0.592, 0.634] |
| DM_lw | 0.593 [0.573, 0.612] |
| 혈관 밀도 | 0.213 (낮을수록 DR, 반대 방향으로 보면 0.787) |

굴곡도 하나만으로는 판별력이 제한적입니다. 혈관 밀도가 굴곡도보다 등급과 훨씬 강하게 연관되어 있습니다 (등급과의 Spearman ρ = −0.54).

### 6.7 민감도 분석 (Spearman ρ)

| 분석 조건 | DM | ICM | **SOAM** | CE | TD |
|---|---|---|---|---|---|
| 기본 (품질 필터) | 0.158 | 0.202 | **0.287** | 0.275 | 0.229 |
| 품질 필터 없음 | 0.157 | 0.206 | 0.262 | 0.250 | 0.220 |
| 선명한 영상 절반 | 0.122 | 0.149 | 0.261 | 0.250 | 0.184 |
| 긴 세그먼트 (≥80px) | 0.134 | 0.206 | 0.261 | 0.241 | 0.217 |
| 굵은 혈관 (폭 ≥4px) | 0.099 | 0.132 | 0.238 | 0.205 | 0.141 |
| 길고 굵은 혈관 | 0.079 | 0.136 | 0.211 | 0.173 | 0.141 |
| 4등급 제외 | 0.145 | 0.183 | 0.274 | 0.264 | 0.216 |

- **모든 조건에서 모든 지표가 같은 방향(양의 연관)** 이었습니다.
- 굵고 긴 혈관만 남기면 연관이 약해집니다(SOAM 0.29 → 0.21). 연관의 일부는 가늘거나 짧은 혈관에서 오지만, 병변 오분할이 적은 굵은 혈관에서도 연관이 남습니다.
- 혈관 밀도·선명도·짧은 조각 비율을 보정한 부분 ρ도 모든 조건에서 SOAM 0.19–0.25로 유지되었습니다.

### 6.8 공변량과의 관계 (Spearman 상관 행렬)

- SOAM은 혈관 밀도와 거의 무관하고(ρ ≈ 0.00), 선명도와도 거의 무관합니다(−0.08).
- 반면 짧은 조각 비율(0.36)·세그먼트 수(0.26)와는 약한 양의 상관이 있습니다. 혈관이 잘게 쪼개질수록 SOAM이 커지는 경향이 있으므로, 짧은 조각 비율을 보정 변수에 넣었습니다.
- 등급은 혈관 밀도(−0.54), 선명도(−0.44)와 가장 강하게 연관되어 있습니다.

## 7. 해석과 논의

1. **DR 등급과 굴곡도의 연관은 실재하지만 크지 않습니다.** 가장 신뢰할 수 있는 SOAM에서 ρ ≈ 0.29, 보정 후 1 SD당 오즈비 1.83입니다. 분할 오차의 방향(DR군에서 과소 측정), 보정 분석, 7가지 민감도 분석이 모두 같은 결론을 가리킵니다.
2. **FIVES와 APTOS의 결과가 달랐습니다.** FIVES 정답 기준으로는 DR군이 정상군보다 더 구불구불하지 않았습니다. 가능한 이유는 다음과 같습니다.
   - FIVES의 DR 200장이 어떤 단계로 구성되었는지 알 수 없습니다. 반면 APTOS는 등급별 비교가 가능하며, 증가가 경증부터 나타났습니다.
   - FIVES 비교는 질환군 대 정상군이고, 질환군 영상은 혈관 밀도가 낮아 길이 가중 평균이 굵은 혈관 쪽으로 기울 수 있습니다.
   - 두 데이터는 촬영 기관과 인구 집단이 다릅니다.
3. **영상 품질과 등급이 얽혀 있습니다.** APTOS에서 0등급 영상은 다른 등급보다 뚜렷이 선명했고, 품질 필터에서 2·4등급이 더 많이 제외되었습니다. 선명도를 보정하고 선명한 영상만 남겨도 연관이 유지되었지만, 수집 과정에서 생긴 차이를 완전히 배제할 수는 없습니다.
4. **혈관 밀도 감소가 굴곡도 증가보다 더 뚜렷한 신호였습니다.** 이는 DR에서 혈관이 실제로 줄어든 결과일 수도 있고, 병변·흐림 때문에 혈관이 덜 분할된 결과일 수도 있습니다. 이 둘을 구분하는 것은 후속 과제입니다.

## 8. 한계

- 나이, 고혈압, 당뇨 유병기간을 보정하지 못했습니다. 특히 고혈압은 굴곡도에 큰 영향을 주므로 결과는 **연관성**으로만 해석해야 합니다.
- APTOS에는 환자 ID가 없어 양안 중복을 제거할 수 없습니다.
- APTOS에는 혈관 정답이 없어 외부 데이터의 분할 정확도를 직접 측정할 수 없습니다. FIVES 일치도와 민감도 분석으로 간접 확인했습니다.
- DM·ICM은 측정 신뢰도가 낮습니다(ICC < 0.5).
- 동맥과 정맥을 구분하지 않았고, 시신경유두 기준 측정 영역(zone B/C)을 적용하지 않았습니다.
- 굴곡도 후처리 파라미터는 합성 곡선으로 정했으며, 실제 영상에 맞춘 최적화는 하지 않았습니다.
- 단일 학습 결과입니다. 재학습하면 수치가 소수점 둘째–셋째 자리에서 달라질 수 있습니다.

## 9. 실행 방법 (Kaggle)

1. Kaggle에서 **New Notebook → File → Import Notebook**으로 노트북을 불러옵니다.
2. **Settings:** Accelerator `GPU T4 x2`, Internet On
3. **Add Input → Competitions:** `APTOS 2019 Blindness Detection` (대회 규칙 동의 필요). FIVES는 자동으로 내려받습니다.
4. **Save Version → Save & Run All**. 브라우저를 닫아도 끝까지 실행되고 모든 출력이 버전에 저장됩니다.
   - 전체 소요: 학습 약 70분 + FIVES 분석 약 10분 + APTOS 약 30분 + 통계
   - 빠른 확인: `CFG.APTOS_MAX = 300`
   - 재실행: 이전 버전 출력(`unet_fives_best.pt`)을 Input으로 붙이면 학습을 자동으로 건너뜁니다.

### 주요 설정 (`CFG`)

| 항목 | 값 | 설명 |
|---|---|---|
| `IMG_SIZE` | 1024 | FOV 지름 정규화 크기 |
| `EPOCHS` / `BATCH` / `CROP` | 80 / 8 / 512 | 학습 설정 |
| `CLDICE_W` | 0.5 | clDice 가중치 |
| `MIN_SEG_LEN` / `SPUR_LEN` | 40 / 12 | 최소 세그먼트 길이, 잔가지 제거 길이(px) |
| `SPLINE_S` / `STEP` | 0.5 / 2.0 | 스플라인 평활 강도, 재샘플 간격 |
| `KAPPA_MIN` / `MIN_RUN` / `END_TRIM` | 0.01 / 4 / 5 | 변곡점 판정, 양 끝 제외 샘플 수 |
| `APTOS_MAX` | None | 처리할 APTOS 영상 수 (None = 전체) |
| `REFERABLE` | 2 | 의뢰 필요 DR 기준 등급 |
| `SHORT_LEN` | 80 | 짧은 조각 기준 길이(px) |
| `N_BOOT` | 2000 | 부트스트랩 반복 수 |
